Модуль «Авторизация»
Предназначен для ввода учетных данных (логин, пароль) сотрудников агропредприятия. Обеспечивает разграничение прав доступа и определение доступных интерфейсов в зависимости от роли (Менеджер, Руководитель склада, Коммерческий директор, Генеральный директор).
Функции модуля:
- Аутентификация пользователей по персональным данным.
- Блокировка несанкционированного доступа.
- Определение роли для фильтрации доступных функций в Главном меню.
2. Модуль «Навигационное меню» (Главное меню)
Центральный интерфейсный узел программы. Обеспечивает сквозную навигацию между всеми функциональными блоками и подсистемами.
Функции модуля:
- Быстрый переход в рабочие разделы (Справочники, Продажи, Закупки, Склад, Отчетность).
- Отображение системных уведомлений.
3. Раздел «Справочники»
Отвечает за ведение условно-постоянной информации (НСИ) предприятия. Поддерживает поиск, фильтрацию и сортировку данных.
Функции модуля:
- Справочник контрагентов: Ввод и хранение данных покупателей и поставщиков (Наименование, ИНН, Контакты, Тип).
- Справочник номенклатуры: Ведение базы с/х культур (Наименование, Единица измерения, Базовая цена, Класс качества).
4. Раздел «Продажи»
Обеспечивает полный цикл работы с клиентами на основе прецедента UC-01 и требований к первичным документам (UC-04).
Функции модуля:
- Создание заказов на продажу: Интерфейс выбора покупателя, подбора номенклатуры (культура, количество, цена) и сохранения документов в статусе «Новый».
- Формирование пакета документов: Автоматическая генерация на основе данных заказа комплекта документов (Счет на оплату, Договор купли-продажи, ТОРГ-12, ТТН) с возможностью экспорта в PDF.
5. Раздел «Складской учет»
Интерфейс для синхронизации бумажного учета на складах с информационной системой (UC-02, UC-05).
Функции модуля:
- Проверка и фиксация актуальных остатков: Форма для ручного ввода подтвержденных руководителями складов данных (после их сверки с бумажными журналами) с фиксацией даты и времени проверки.
- Внесение данных об отгрузке/приемке: Модуль для изменения статуса заказов («Отгружен» / «Принят на склад») и ввода фактического объема продукции, прошедшего через склад.
6. Раздел «Закупки»
Рабочее место Генерального директора для контроля обеспечения агрокомплекса сырьем и продукцией (UC-03).
Функции модуля:
- Формирование заказов поставщикам на закупку продукции.
- Вывод ретроспективных данных (истории прошлых закупок) для анализа цен.
7. Раздел «Аналитические отчеты»
Модуль агрегации выходных данных для руководства компании.
Функции модуля:
- Формирование сводных отчетов по продажам и закупкам.
- Расчет текущих складских запасов на основе последних зафиксированных ручных данных.
- Контроль дебиторской задолженности покупателей.
